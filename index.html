《夜脉工坊》隐私政策

开发与运营主体：游戏外溢工作室

更新日期：2026年10月10日
生效日期：2026年10月10日

游戏外溢工作室（以下简称“我们”）尊重玩家的隐私。本政策说明您使用《夜脉工坊》时，游戏涉及哪些信息、如何处理这些信息，以及如何联系我们。

本政策适用于以下两个版本，并依据其实际功能制定：

  • TapTap 小游戏 1.0.0（在 TapTap 应用内运行，下称“小游戏”）：接入 TapTap 登录与 TapTap 激励视频广告，游戏进度保存在本地。见第一至第三部分。
  • 安卓测试版 0.3.9-test（独立安装包，下称“安卓测试版”）：单机、无登录、无广告。见第四部分。

两个版本均无应用内购买、无付费功能，我们不运营接收玩家数据的游戏服务器，游戏进度不会通过游戏上传给我们。

一、小游戏：TapTap 登录

小游戏启动时会调用 TapTap 平台提供的登录接口。该接口由 TapTap 平台处理，平台仅向游戏返回一个临时登录凭证（code）。小游戏不会将该凭证发送到任何服务器，也不会读取您的 TapTap 昵称、头像、手机号等账号资料；我们因此不会获得您的 TapTap 账号信息。

TapTap 账号本身及登录过程中的信息处理，适用易玩（上海）网络科技有限公司（TapTap）的隐私政策及 TapSDK 隐私政策。

二、小游戏：本地存档

为保存进度和设置，小游戏使用 TapTap 小游戏提供的本地存储，读写以下数据：

  • 游戏进度：矿粒、矿堆、矿工数量、升级、天赋、矿层、代数、能源、装置状态及加速状态等；
  • 设置与引导记录：音效开关、画面效果开关、教程完成情况；
  • 广告奖励记录：已完整观看激励视频所对应的本地奖励编号与使用情况（用于防止重复发放奖励）；
  • 累计游玩时长：用于在首次启动后 60 秒内不开放任何广告。

这些数据不包含姓名、手机号或身份信息，仅保存在您的设备 / TapTap 为小游戏提供的本地环境中，用于继续游戏和记住设置。为减少进度丢失，游戏会同时保存本地备份。我们没有云存档服务器，无法远程读取、恢复或删除您的本地进度。

三、小游戏：激励视频广告与第三方信息处理

小游戏提供可选的“激励加速”：只有在您主动点击并确认后，才会通过 TapTap 小游戏广告能力播放激励视频广告；完整观看后，开采与运输速度提升一段时间。游戏不会自动弹出广告，首次启动后 60 秒内不开放广告，您可以随时关闭广告，未看完不发放奖励，不看广告也可以正常游玩。

该广告服务由 TapTap 平台通过 Dirichlet（TapADN，上海艾得蒽数字科技有限公司）提供。广告的请求、展示与统计由平台及广告服务方的组件直接完成，游戏本身不收集、不上传设备标识等信息。按照其公开说明，广告服务为广告投放、监测归因、反作弊、统计分析和服务稳定，可能自行收集设备信息（如设备品牌型号、系统版本、屏幕信息、设备标识符）、网络信息（如 IP 地址、网络状态）、应用信息、传感器信息、广告展示 / 点击等交互数据、粗略位置信息和性能数据等。TapADN 还可能调度其合作的下游广告平台完成广告展示，由相关第三方直接收集和处理信息。具体以以下官方页面为准：

  • TapADN（Dirichlet）隐私政策
  • TapADN SDK 合规使用说明
  • TapTap 第三方信息共享清单（含 TapADN 及其下游广告平台的信息共享说明）

我们只能在 Dirichlet 媒体管理平台查看广告位的汇总数据（如展示次数、收益），无法据此识别具体玩家。

四、安卓测试版（0.3.9-test）

安卓测试版为单机游戏，无账号登录、联机、云存档功能，未接入广告、统计分析或社交分享 SDK。安装包未声明联网权限，也不请求相机、麦克风、通讯录、定位或外部存储权限。游戏进度与设置（内容同第二部分，不含广告记录）保存在应用自身的本地存储中，不会上传给我们。

如果您通过 TapTap 下载该安装包或通过 TapPlay 运行，平台自身的账号、下载及运行环境的信息处理适用平台的隐私政策。

五、您主动联系时提供的信息

您可以发送邮件至 23863806@qq.com 联系我们。当您主动反馈问题时，我们会收到您的发件邮箱、邮件内容及您主动附上的截图或其他文件，仅用于联系您、排查问题、回应请求及处理相关争议。您不需要提供与问题无关的敏感信息，也不必提供任何信息即可游玩。

往来邮件通过邮件服务提供方传送和保存。我们仅在处理您的请求及履行法律义务所需的期限内保留相关信息；目的完成且无需继续保留时予以删除或匿名化。

六、存储、安全与信息提供

本地存档的保存期限由您保留游戏及其数据的时间决定。设备、操作系统和平台的备份或迁移，由相应提供方及您的设置决定。

我们不出售您的个人信息，不将您主动提供的联系信息用于广告营销。除处理您请求所必需的邮件服务、取得您另行同意或法律法规要求的情形外，我们不向第三方提供您的联系信息。第三部分所述广告服务方直接收集的信息，由其按各自政策处理。如发生需要告知您的个人信息安全事件，我们将依法采取处理和通知措施。

七、您的权利：查看、重置、删除与撤回

  • 查看进度与设置：可在游戏界面及设置中查看。
  • 重置进度：设置中的“重新开始”会重置本轮进度，保留音效和画面设置。
  • 删除小游戏本地数据：可通过 TapTap 提供的小游戏数据 / 缓存管理方式清除，具体操作以 TapTap 应用为准，也可咨询平台客服。
  • 删除安卓测试版数据：在系统“设置 → 应用 → 夜脉工坊 → 存储”中选择“清除数据”，或卸载应用。
  • 拒绝广告：广告完全可选，不点击“激励加速”即不会播放。对广告服务方收集的信息，可按第三部分所列政策行使权利，或在设备系统中管理广告个性化设置。
  • TapTap 账号：账号信息的查询、更正、注销请通过 TapTap 平台办理；本游戏不另设游戏账号，因此没有游戏账号注销流程。
  • 联系信息请求：如需查询、更正、删除您通过邮件提供的个人信息或撤回同意，请发邮件说明。我们会在合理核实后尽快处理，法律要求保留的信息除外。

删除本地数据可能导致进度永久丢失，请在操作前确认。

八、未成年人保护

未成年人应在监护人指导下阅读本政策、使用游戏并安排游玩时间。小游戏的防沉迷由 TapTap 平台统一实施。本游戏无付费内容，不以收集未成年人个人信息为目的。反馈问题时，请勿发送儿童的姓名、学校、地址等无关信息；监护人如发现儿童向我们提供了不必要的个人信息，可联系下方邮箱申请删除。

九、本政策网页

本网页只用于展示隐私政策，无需登录，不包含我们设置的广告、统计分析脚本或表单。网页托管服务可能为提供访问和安全保障处理 IP 地址、浏览器信息、访问时间等必要技术信息；我们不会通过本网页读取您的游戏进度。

十、政策更新与联系我们

如游戏新增联网、云存档、付费或其他涉及信息处理的功能，我们会在启用前更新本政策并以适当方式告知。更新后的日期会在本页注明。
